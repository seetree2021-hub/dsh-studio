# DSH Studio · 新用户旅程（端到端工作流）

> 目标：让用户从"下载"到"开始运营"全程低门槛——**用户只做"说"和"看"，其余由系统封装**。

---

## 用户旅程总览

```
下载 ──→ 新建项目 ──→ 模式建立(对话) ──→ 确定插件/环境 ──→ 便签+面板运营
 30秒       30秒          10-15分钟            由AI推荐           每天
```

## 第 0 步 · 下载（30 秒）

```bash
git clone https://github.com/seetree2021-hub/dsh-studio.git
# 或 GitHub 页面 Code → Download ZIP
```

## 第 1 步 · 新建项目（30 秒）

```powershell
cd C:\your-workspace
.\dsh-studio\docs\project-template\new-project.ps1 my-studio
```

脚本自动生成项目骨架（一个文件夹，全模板）：

```
my-studio/
├── note-data.json           # 便签数据（已初始化 2 条引导任务）
├── 01-business-model.md     # 商业模式画布（待对话填写）
├── 02-operations-panel.md   # 运营工位看板（模板）
└── README.md                # 项目说明（含下一步指引）
```

## 第 2 步 · 模式建立（10-15 分钟，纯聊天）

在 DSH（AI 运营总监）会话里说一句话：

> **「模式建立」**

AI 按《questionnaire.md》问卷分 4 组逐步提问（每次 1-2 个问题，不抛问卷）：
你的现状 → 收入与产品 → 成本与资源 → 目标与约束。

全部回答后，AI 自动产出（写入项目文档）：
- **《01-business-model.md》**：商业模式画布九要素 + 运营策略 + 定价/现金流要点
- **插件推荐清单**（按业务线映射，见《plugin-map.md》）
- **便签初始任务**（note-data.json 更新为真实任务）

## 第 3 步 · 确定插件与环境（由 AI 推荐，用户确认）

AI 根据商业模式推荐需要哪些模块，并给出环境搭建说明：

| 你的业务线 | AI 会推荐 | 需要你准备的环境 |
|---|---|---|
| 内容/自媒体 | 内容包 + 发布清单 + 数据回流 | 平台账号后台、剪辑工具 |
| 产品制造（陶瓷等） | 产品线卡 + 库存/烧制计划 | 设备台账、库存表 |
| 设计/项目服务 | 项目卡（报价/进度/催款） | 设计工具（CAD/EDA） |
| 通用 | 便签 + 运营面板 + 商业模式面板 | 无 |

用户确认 → AI 生成对应模块文档与任务。

## 第 4 步 · 运营管理（每天）

- **桌面便签**：看今日任务（四象限）→ 点📄开文档照做 → 打勾
- **运营面板**：工位看板/今日行动/拍板/数据
- **商业模式面板**：商业模型复盘与优化
- **AI 运营总监**：每天更新便签数据 + 面板文档 + 留言反馈

---

## 操作难度设计原则（封装目标）

| 用户动作 | 系统（AI/脚本）动作 |
|---|---|
| 说"模式建立" | 引导式提问（4 组，逐步） |
| 回答问题（现状/数据） | 生成商业画布 + 策略 + 插件清单 |
| 说"开始运营" | 便签数据 + 面板初始化 |
| 每天打勾 | AI 登记进度、更新计划、留言 |
| 说"优化商业模式" | 按现状复盘并调整模型 |

**用户永远不需要**：写 JSON、配环境、读协议、改代码——除非想参与开源迭代。
