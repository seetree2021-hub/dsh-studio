# DSH Studio · 使用与迭代指南

> 版本：v0.1.0（2026-08-17）｜ 用 DeepSeek Harness 搭建自己的自动工作室

---

## 一、它由三件套组成（不用"安装"，是"运行"）

DSH Studio 不是一个需要安装的软件，而是三件套协同的"自动工作室系统"：

| 件 | 是什么 | 在哪 | 谁维护 |
|---|---|---|---|
| **智能层** | DSH 会话 = AI 运营总监 | 本机 DSH / 云端 | AI：规划/文案/登记/优化 |
| **数据层** | `note-data.json` + 面板文档（工作台/商业模式/复盘） | 本机工作目录 | AI 每天更新，便签写回勾选 |
| **界面层** | 桌面任务便签（WinForms 原生，免登录零安装） | 本机开机自启 | 用户：看任务/打勾/开文档 |

> 运行入口就一条命令（已配开机自启）：
> `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -WindowStyle Hidden -File src\desktop-note.ps1`

## 二、日常怎么用（用户的每一天）

1. **开机** → 便签自动弹出（当天任务：四象限/时段/文档链接）
2. **干任务** → 点任务右侧 📄 图标打开对应文档（口播稿/发布清单/项目卡），照做
3. **完成打勾** → 便签自动保存，进度条前进
4. **临时任务** → 顶部输入框回车添加（自动归入 Q4，AI 下次会话读取登记）
5. **看面板** → 底部「运营面板」「商业模式」按钮一键打开
6. **AI 反馈** → 底部留言区显示 AI 处理结果（3 秒自动刷新）

## 三、迭代怎么进行（两层）

### 层 1：配置层迭代（零代码，AI 每天自动做）

运营层面的优化全部在**数据/文档**上完成，不需要改程序：

- 每天更新 `note-data.json`（任务/链接/四象限/留言）
- 每周更新运营面板（工位看板/今日行动/拍板）、商业模式文档、复盘文档
- 优化发布安排、定价策略、现金流作战顺序

> 这就是"自动工作室"的日常：**AI 当运营总监，用户当执行者**。

### 层 2：代码层迭代（开源开发，改源码→发布）

功能层面的迭代走开源 SOP：

```
1. 提出需求（对话里说）
2. AI 改源码（desktop-note.ps1 / 协议 / 新面板）
3. 本机验证（重启便签看效果）
4. git commit → push GitHub（GitHub Desktop 已登录）
5. 发 Release 版本（v0.1.0 → v0.2.0 …）
6. 更新 CHANGELOG / README / Roadmap
```

仓库地址：`https://github.com/seetree2021-hub/dsh-studio`
本地开发目录：`F:\zhanlue\AI studio\DSH Studio\opensource\dsh-studio`

## 四、什么时候才"安装插件"？

当 DSH Studio 演进为 **DSH cordis 官方插件**（Roadmap 第二步）时，才需要安装：

```bash
dsh plugin --profile web add dsh-studio
```

安装后三面板（任务便签/运营/商业模式）直接嵌进 DSH Web 界面，同一份 JSON 两端同步。
**在那之前，现在的本地运行方式就是完整可用的状态。**
