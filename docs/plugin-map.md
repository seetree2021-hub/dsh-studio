# DSH Studio · 插件模块推荐映射

> 用途：商业模式建立后，AI 按业务线推荐需要哪些 DSH Studio 模块与环境准备。
> 原则：只推荐当前阶段用得上的，宁少勿多，避免配置负担。

---

## 业务线 → 推荐模块

| 业务线（识别关键词） | 推荐模块 | 产物文档 | 环境准备 |
|---|---|---|---|
| **内容 / 自媒体**（账号、粉丝、发布、视频） | 内容包 + 发布清单 + 数据回流 | 选题包/发布清单/账号数据 | 平台创作后台、剪辑工具、素材目录 |
| **产品制造**（陶瓷、手作、烘焙、小生产） | 产品线卡 + 库存/生产计划 | 产品现状卡、批次/烧制记录 | 设备台账、库存表 |
| **设计 / 项目服务**（接单、图纸、方案） | 项目卡（报价/进度/催款） | 项目清单、收款节点 | 设计工具（CAD/EDA/渲染） |
| **销售 / 电商**（开店、订单） | 商品卡 + 订单/回款表 | 上架清单、订单台账 | 店铺后台 |
| **知识 / 咨询**（培训、课程） | 内容包 + 客户关系卡 | 课程/客户清单 | 内容平台 |
| **通用（多业务混合）** | 便签 + 运营面板 + 商业模式面板 | 工作台/模式文档 | 无 |

## 环境搭建清单模板（AI 生成给用户）

```
【你的工作室环境清单】
□ 数据目录：按《目录约定》建立（项目/素材/成品归档）
□ 平台账号：列出需要登录的后台（如创作服务平台、店铺）
□ 工具：列出需要的软件（如剪辑、CAD、窑炉控制器）
□ 便签：开机自启已配置（启动文件夹放 desktop-note.ps1 快捷方式）
□ 面板：运营面板/商业模式面板路径已写入便签
```

## 判定逻辑（AI 执行）

1. 从商业模式输入中识别业务线关键词（Q2/Q3/Q4 的回答）
2. 命中多个业务线 → 推荐多个模块，标注优先级（按收入占比）
3. 无法识别 → 走"通用"推荐
4. 用户确认后 → 生成对应模块文档 + 便签任务 + 环境清单

## 约定

- 模块文档统一放项目目录，命名 `NN-module.md`（01 business-model、02 operations-panel、03+ module）
- 便签数据 `note-data.json` 中的 link 字段指向对应模块文档（点📄即开）

## 安装方式：自装 or AI 推送

用户需要的应用/插件有两条路径（可并行）：

1. **自己安装**：任何满足你工作流的外部工具（设计软件、剪辑、电商后台、统计脚本……）
   直接安装即可——DSH Studio 不做强制依赖，只通过便签链接/面板把它们组织进工作流
2. **AI 按需推送**：说一句「我要做 XX」→ AI 按本表业务线识别 → 推送推荐模块清单
   （含：用什么工具 / 怎么装 / 建什么文档 / 便签挂什么任务），你确认后 AI 全部落地

> 原则：**AI 推荐、用户决定**。AI 永不自动安装软件，只给清单与步骤。
