# 小型工作室商业模式通用框架（SMF v1.0）

> DSH Studio 的核心智力资产：面向 **1-10 人小型工作室/个人工作室**的轻量商业模式设计与运行框架。
> 参照：商业模式画布（BMC）/ 精益画布（Lean Canvas）/ OPC 一人公司方法论 + 真实工作室实践（产品+服务+内容混合案例）。
> 使用方式：AI 按《questionnaire.md》引导填写 → 本框架把回答组织成可运行的商业模式 → 便签+面板执行。

---

## 一、框架总览：四层结构

```
┌─ ① 定位层  我是哪种工作室？（服务/产品/内容/混合）
├─ ② 设计层  商业模式画布（9 要素）+ 风险控制
├─ ③ 运营层  周循环引擎：任务便签 + 面板 + AI 运营总监（DSH Studio 落地）
└─ ④ 演化层  每周复盘 / 每月模式审计（画布是活的，不是文档）
```

小型工作室的铁律：**资源有限 → 模式必须"轻"**（低成本验证、快速迭代、AI 增强一人多岗）。

## 二、① 定位层：工作室类型速查

| 类型 | 典型 | 收入结构 | 关键成功 | 主要风险 | 对策 |
|---|---|---|---|---|---|
| **服务型** | 设计/咨询/开发/外包 | 项目制按单 | 交付口碑+获客渠道 | 淡旺季波动、单一大客户 | 预售/长协/定金；内容获客；多客户分散 |
| **产品型** | 手作/制造/电商/食品 | 卖货毛利 | 产品差异化+复购 | 库存积压、毛利薄 | 小批量+预售；跑量款+精品款组合 |
| **内容型** | 自媒体/知识付费 | 流量变现（广告/带货/课程） | 内容粘性+私域 | 流量波动、变现滞后 | 多平台+私域；用产品/服务承接流量 |
| **混合型** ⭐ | 产品+服务+内容并行 | 多线错峰 | 现金流互哺（服务养产品/内容养品牌） | 精力分散 | 主线明确，AI 接管运营 |

> 多数工作室是混合型。定位层输出 = 主线与辅线排序（收入占比）。

## 三、② 设计层：商业模式画布（9 要素填空模板）

| 要素 | 填空提示 | 示例 |
|---|---|---|
| 客户细分 | 谁付钱？分几类 | 终端消费者 / 企业客户 / 观众 |
| 价值主张 | 你解决什么、独特在哪 | 原矿釉柴烧工艺；16年设计能力；AI 运营模式 |
| 渠道 | 怎么触达 | 内容平台引流 → 私域 → 直播间/市集 |
| 客户关系 | 怎么维护 | 定制沟通、孤品叙事、售后周期 |
| 收入来源 | 各条线占比 | 服务费 50% / 产品 40% / 内容 10% |
| 核心资源 | 人/设备/能力/供应链 | 窑炉、设计能力、供应商、AI |
| 关键活动 | 每天主要干什么 | 研发、制作、内容、交付 |
| 关键伙伴 | 供应商/外包/合作 | 材料商、外发厂、合作老师 |
| 成本结构 | 钱花哪 | 房租、材料、外包、设备 |

**风险控制（参照 Lean/OPC）**：画布填完自查三件事
1. 单点依赖：收入是否过度依赖单一客户/渠道/产品？→ 分散或备胎
2. 验证先行：新想法先小成本验证（最小产品先卖/先接一单）再投入
3. 缓冲垫：现金流至少覆盖 3 个月生存成本

## 四、现金流模型（小型工作室的生存核心）

**三账户思维**：
| 账户 | 用途 | 规则 |
|---|---|---|
| 生存账户 | 房租/生活/社保 | 优先保障 |
| 业务账户 | 材料/外包/推广 | 投入产出比 ≥3 |
| 投资账户 | 设备/研发/品牌 | 盈利后投入 |

**回血优先原则**：
1. 先验证后投入（预售/定金/先接单）
2. 产品线组合：跑量款（走量回流）+ 主力款（利润）+ 精品款（品牌溢价）
3. 内容/服务的现金流错峰：服务养产品、内容养品牌

**定价公式**：`成本 × 3` 起步 → 市场锚点修正（查同类定价）→ 阶梯定价（入门/主力/精品三档）

## 五、增长飞轮

```
内容（展示专业/过程）→ 信任 → 客户 → 复购 + 转介绍 → 更多内容/案例 → …
```
- 内容型/混合型工作室的免费获客引擎（DSH Studio 内容模块承接）
- 服务型：案例即内容；产品型：制作过程即内容

## 六、运营层：周循环引擎（DSH Studio 落地）

| 周期 | 动作 | 载体 |
|---|---|---|
| 每天 | 看便签任务 → 执行 → 打勾 → AI 登记 | 任务便签 |
| 每周 | 复盘数据 → 调下周任务 → 商业模式微调 | 运营面板 + 便签 |
| 每 1-2 周 | 「优化商业模式」→ AI 对照画布找偏差更新 | 商业模式卡 |

## 七、④ 演化层：让框架适配你自己

1. **换业务线**：面板/主题色/分组由 `dsh-studio.config.json` 配置（任意增删）
2. **改问卷**：`docs/questionnaire.md` 增删问题（AI 引导时生效）
3. **换模块**：需要什么工具/插件——自装 或 让 AI 按业务线推送（`docs/plugin-map.md`）
4. **框架可改**：本框架是**起点不是终点**——四类模式可混合、画布要素可增删、飞轮可替换

## 八、参考案例（脱敏：手作工作室 · 产品+服务+内容混合）

> 一个真实工作室的框架实例（数据已泛化）：手工陶瓷 + 工业设计服务 + 陶瓷内容自媒体

- **定位**：混合型（产品 40% / 服务 40% / 内容 20%）
- **画布要点**：客户=茶器用户+本地企业+观众；价值=传统工艺当代化+设计能力；渠道=内容→私域→直播；资源=窑炉+设计+AI 运营+素坯供应链；伙伴=釉料老师+拉坯师傅+外发厂
- **现金流**：生存=房租+生活；业务=坯料+烧制+外包；投资=设备（盈利后）
- **产品组合**：跑量款（日常杯 30-50 元）→ 主力款（釉色精品 70-170 元）→ 精品款（柴烧孤品 130-300 元）
- **飞轮**：双线叙事内容（寻矿+师承）→ 信任 → 直播/私域转化 → 复购+工业转介绍
- **风险对策**：工业单分散客户、陶瓷走预售、内容多平台
