# examples · 示例项目（演示用）

> ⚠️ 本目录为**演示示例**，全部数据为虚构（人物/项目/金额均为假），仅用于展示 DSH Studio 新用户旅程的产物结构。
> 实际使用：运行 `..\docs\project-template\new-project.ps1 你的项目名` 创建自己的项目，
> 然后在 DSH 里说「模式建立」让 AI 引导填写。

## 本示例展示

```
示例项目/
├── note-data.json        # 模式建立后生成的初始任务（四象限+链接）
├── 01-商业模式建立.md     # 商业模式画布（对话产出）
└── README.md             # 项目说明
```
