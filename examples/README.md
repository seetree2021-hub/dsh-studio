# examples · 示例项目（演示用）

> ⚠️ 本目录为**演示示例**，全部数据为虚构（人物/项目/金额均为假），仅用于展示 DSH Studio 新用户旅程的产物结构。
> 实际使用：运行 `..\docs\project-template\new-project.ps1 your-project` 创建自己的项目，
> 然后在 DSH 里说「模式建立」让 AI 引导填写。

## 本示例展示

```
example-project/
├── note-data.json        # 模式建立后生成的初始任务（四象限+链接）
├── 01-business-model.md  # 商业模式画布（对话产出）
└── README.md             # 项目说明
```

## 如何生成你自己的项目

1. 运行 `..\docs\project-template\new-project.ps1 your-project`
2. 在 DSH 里说「模式建立」→ AI 引导填写
3. 便签+面板开始运营

> 示例数据全部虚构，请勿直接复用；正式项目数据与配置（dsh-studio.config.json）默认不入库。
